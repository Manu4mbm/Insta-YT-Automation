# Content strategy (draft — scripts come after setup)

**Account:** the owner's own. **Niche:** AI + tech for Indian builders/students/devs. Hinglish voiceover by the owner.

## Pillars
1. **Tool explainers** — Claude Code, Antigravity, Codex, Cursor-style agents: what's new, how to use, 1 workflow per reel.
2. **AI terms in 60s** — RAG, MCP, agents, embeddings, tokens, context window, fine-tuning vs RAG…
3. **Build with me** — real builds (sites, automations, JARVIS-style agents) shown as quick wins.
4. **Comparisons / hot takes** — Claude Code vs Codex vs Antigravity, "which should you learn".
5. **Freelance/income with AI** — practical, no hype.

## Reel format
Hook (≤1.5s) → problem/curiosity → teach 1 thing clearly → proof/example → CTA: **"Comment `<KEYWORD>` and I'll DM you the guide"**.
Length 40–60s. Workflow: see docs/REEL-WORKFLOW.md (reference video → script → ElevenLabs audio → reel + thumbnail → approval → post). Visual style from reel-studio (UGC or kinetic); vary per reel.

## Lead magnets (one per reel or per series)
- Cheat sheets / step-by-step guides / prompt packs / CLAUDE.md templates, published as shareable pages (Claude artifact/Docs or Vercel page).
- Keyword per reel: short, unique, uppercase (e.g. `RAG`, `CLAUDE`, `AGENT`, `MCP`).
- DM text: 1 line value + link + soft follow CTA.

## Rules
- Every tool fact verified against current changelog/docs the week of posting.
- No fake stats, no "guaranteed income" claims.
- Script format = reel-studio `script.txt` (one beat per line, *hero* words). Also produce `post.json`: caption, hashtags, keyword, dm_text, guide_url.
