Claude Code Mods: bolo, aur Claude khud bana de

Mod ek chhota add-on hai jo Claude Code ka kaam aur look badal deta hai: naya panel, naya command, ya kisi kaam ko rokna. Code likhna zaroori nahi. Claude ko apne shabdon mein bolo, woh mod khud likh deta hai.

1Shuru karne se pehle

  • Claude Code v2.1.287 ya naya chahiye. Terminal mein claude --version chala ke check karo.
  • Mods Claude Code CLI aur Claude Desktop app ke Code tab mein chalte hain.
  • Kaunse mods chal rahe hain, ye dekhne ya band karne ke liye Claude Code mein /plugin chalao.

2Mod kaise banaye

  1. Claude Code kholo aur likho: "Make a mod that …" aur apni zaroorat batao.
  2. Claude mod bana ke test karega. Jo theek na lage, normal shabdon mein bolo kya badalna hai.
  3. Pasand aaye to Claude se bolo ise install kar de, taaki har session mein chale.

33 ready mods: prompt copy karo

Neeche ka prompt Claude Code mein paste karo. Bas.

Undo button
Make a mod that saves a backup copy of any file or folder before you delete, move or overwrite it, and shows me a Restore button for each backup. If the backup fails, do not go ahead with the action.
Memory meter
Make a mod that shows a small pane beside the chat with how full the context window is after each reply, and what is taking up the most space.
Secret lock
Make a mod that blocks you from reading .env files or any file with "secret", "token" or "key" in its name, and shows me a warning whenever it blocks something.

4Dhyan rakho

  • Mod aapke computer pe Claude Code ke andar chalta hai, isliye sirf bharosemand mods install karo. Kisi aur ka mod lagane se pehle Claude se poochho ki ye kya karta hai.
  • Pehle ek chhota mod banao (jaise Undo button), phir aage badho.
  • Mod banane mein thoda Claude usage lagta hai, par ek baar banne ke baad baar baar kaam aata hai.
