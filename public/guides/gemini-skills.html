Gemini Skills: ek baar banao, baar baar use karo

Skills = aapke saved instructions. Har baar lamba prompt likhne ki jagah, chat mein / lagao, skill ka naam chuno, aur Gemini usi tareeke se kaam karega.

1Kaun use kar sakta hai

  • Personal Google account chahiye (work/school account pe abhi nahi), aur aapki umar 18+ honi chahiye.
  • Gemini mobile app, Mac app, ya gemini.google.com pe milta hai.
  • Rollout dheere dheere ho raha hai. Agar aapko abhi nahi dikh raha, kuch din baad dobara check karo.

2Skill kaise banaye

  1. gemini.google.com kholo → Settings → Skills.
  2. Chaar mein se koi ek tareeka chuno:
    • Chat mein Gemini se bolo: "Mere liye ek skill banao jo …"
    • Recommended se ek ready template lo aur edit karo
    • Blank template: naam, description, instructions khud bharo
    • SKILL.md file (ya .zip) upload karo
  3. Save karo. Bas, skill tayyar.

Tip: description saaf likho ki skill kab use ho. Gemini isi se samajhta hai ki skill khud kab lagani hai.

3Skill kaise use kare

Chat box mein / type karo → apni skill ka naam chuno → apna kaam likho. Ek chat mein ek se zyada skills bhi laga sakte ho. Kai baar Gemini khud bhi sahi skill laga deta hai, jab aapka sawaal skill ki description se match karta hai.

43 ready skills: copy karo, paste karo

Blank template mein naam daalo, phir neeche ka text instructions mein paste karo.

/mera-writing-style
Tum meri writing style mein likhte ho. Meri style: simple Hinglish, chhote sentences, friendly tone, koi bhaari English words nahi. Har message mein: - pehli line mein seedha point - 3–5 lines se zyada nahi - end mein ek clear next step Main jo bhi text doon, use isi style mein rewrite karo. Facts mat badlo, kuch naya mat jodo.
/padhai-notes
Tum mere study partner ho. Main koi topic, chapter ya PDF doon to: 1. 5 bullet points mein simple summary (Hinglish) 2. 3 important terms + ek line ka matlab 3. 5 practice questions (answers end mein alag se) 4. Ek real-life example Agar kuch samajh na aaye to pehle mujhse poochho. Galat facts mat banao.
/insta-caption
Tum Instagram caption writer ho. Main topic ya reel ka idea doon to: - 3 caption options do (Hinglish, har ek 2–3 lines) - pehli line hook ho jo scroll rok de - ek clear call to action (comment / save / follow) - 3 se 5 relevant hashtags, isse zyada nahi Clickbait ya jhoothe claims mat likho.

5Dhyan rakhne wali baatein

  • Gems ab Skills ban rahe hain. Personal accounts pe Gems November 2026 mein band ho rahe hain. Google kehta hai ki purane Gems apne aap skills mein badal jayenge, par apne Gem ke instructions ek baar copy karke rakh lo.
  • Ek saath 100 skills tak active rakh sakte ho.
  • Abhi Canvas aur Deep Research skills ke andar kaam nahi karte.
  • Mobile app pe manually banayi skill kabhi kabhi save nahi hoti. Aisa ho to web (gemini.google.com) se banao.

Features aur availability Google badal sakta hai. Latest jaankari ke liye Google ka official help page dekho: Create and manage skills · Gems se Skills
