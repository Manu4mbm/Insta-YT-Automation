INSTAGRAM + YOUTUBE
AUTOMATION SETUP

Wahi system jo @yourhandle chalata hai: reels time pe auto-post, comment pe auto-DM (follow ke baad link), aur har reel YouTube Short bhi. Official APIs, free tiers.

System ke 5 parts

  • Claude Code — code likhta hai, deploy karta hai (ye server nahi hai)
  • Supabase (free) — queue (posts), DM log, rules, video storage
  • Vercel (Hobby) — serverless functions: publish, poll, webhook
  • Instagram API with Instagram Login — publishing + private replies
  • YouTube Data API v3 — Shorts / videos upload

Timer: Vercel Hobby pe cron sirf daily chalta hai, isliye har-minute jobs Supabase pg_cron + pg_net se call karo.

1

Meta app banao

developers.facebook.com → Create app → use case "Manage messaging & content on Instagram" (Instagram API with Instagram Login). Instagram professional (Business/Creator) account chahiye — Facebook Page zaroori nahi.

Permissions: instagram_business_basic, instagram_business_content_publish, instagram_business_manage_comments, instagram_business_manage_messages.

Token, app secret — sirf .env / Vercel env vars mein. Kabhi code ya chat mein nahi.

2

Claude Code ko plan do

Ek folder mein CLAUDE.md likho (goal, stack, rules), phir Claude Code se bolo:

Reels schedule pe Instagram pe post hon (Supabase queue + cron),
comment pe ek private reply DM jaye, follow ke baad hi link mile,
aur har reel YouTube Short bhi upload ho. Vercel pe deploy karo.
3

Auto-posting (time pe)

  • Reel = container (media_type=REELS, public video_url) → status FINISHED → media_publish.
  • Processing mein time lagta hai — container ~16 min pehle banao, publish theek slot pe.
  • Publish ke baad CTA wala pehla comment khud post karo (pin aap app se karo).
  • Limit: 24 ghante mein max 100 API posts.
4

Comment → DM (follow-gated)

  • Ek comment pe sirf ek private reply (recipient: {comment_id}), comment ke 7 din ke andar.
  • Reply mein button: "Follow kar liya ✅" → follow check (is_user_follow_business) → follower ko link, warna halka reminder.
  • User ne reply/tap kiya to 24 ghante ka messaging window khulta hai.
  • Har reel ka apna resource; ek user ko ek reel ka resource ek hi baar.
  • Sirf unhi ko DM jinhone us reel pe comment kiya — spam nahi.
5

Webhooks vs polling

Live webhooks (comments/messages) ke liye Meta App Review / Advanced Access maangta hai. Tab tak ek cron har minute naye comments padh sakta hai (official API, rate limits ke andar). App Review ke baad webhooks on kar do.

6

YouTube Shorts auto-upload

  • Google Cloud project → YouTube Data API v3 enable → OAuth consent (External, In production) → OAuth client (Web) + redirect URI.
  • Ek baar login → refresh token server pe save → resumable upload, publishAt se schedule.
  • 9:16 aur 3 min tak ki video = Short.
  • Naye (unverified) API projects ki uploads private lock ho sakti hain jab tak Google ka API audit pass na ho.
