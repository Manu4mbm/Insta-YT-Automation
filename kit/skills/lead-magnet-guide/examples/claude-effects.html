108 video skills + effects. Sab Claude Code mein.

Na Premiere, na After Effects, na CapCut. Claude Code mein apni video do, /effects likho aur effect ka naam — edit ready. Reel mein jo 7 effects dikhaye the, wo neeche highlight hain.

1

Claude Code kholo

Claude desktop app ya terminal — dono chalega. Plan pe Claude Code access hona chahiye.

2

Skill install karo (ek line)

Claude Code mein ye paste karo, Claude khud install kar dega:

Install the skill from github.com/Vibha-Ramprakash/claude-video-effects into ~/.claude/skills/effects

Ya terminal mein khud:

git clone https://github.com/Vibha-Ramprakash/claude-video-effects ~/.claude/skills/effects

Windows (PowerShell) pe path $HOME\.claude\skills\effects rakho. Install ke baad Claude Code restart karo. Pehli baar setup ~2 minute leta hai (ffmpeg + Python khud install karta hai).

3

Video do aur effect bolo

Vertical (9:16) talking-head video best hai. Chat mein video drag karo aur likho:

/effects orbit from 3 to 6 seconds
/effects spotlight when I say "Claude", with the word CLAUDE behind me
/effects glass-widgets for the first 3 seconds
/effects checklist from 8 to 11 seconds

Ek saath kai effects bhi: "locked-on 6–10s, phir orbit 10–13s, phir reject-stamp on 'no'". Claude pehle kuch frames check karta hai (face cover na ho), phir video_effects.mp4 bana deta hai — audio wahi rehta hai.

4

Pro tips

  • Har effect 1.5–4 second ka rakho — chhota = zyada punchy.
  • Text wale effects mein apna word do: text=CLAUDE, name=Aman, handle=@yourhandle.
  • orbit, carousel-spin, phone-fan ke liye apni reels ke screenshots ka folder do (images).
  • Sound effects aur music alag se daalo (CapCut ya Claude se mix karwa lo).
